# 1. Propósito

Este documento es el punto de control oficial del módulo Biblioteca.

A diferencia de la Especificación Funcional, este documento tiene como
objetivo administrar el proyecto durante su desarrollo. Debe responder
en todo momento:

-   ¿Qué existe?
-   ¿Qué falta?
-   ¿Qué estamos construyendo?
-   ¿Qué decisiones hemos tomado?
-   ¿Cuál es el siguiente paso?

Todo cambio funcional o técnico relevante deberá reflejarse aquí.
